# Arrera App Menu - Extension GNOME Shell

Extension de menu d'applications moderne et flottante développée pour la distribution **Arrera Blue Linux**.

## Fonctionnalités

- **Menu d'applications flottant** : Interface élégante avec effet acrylique / verre dépoli.
- **Recherche instantanée** : Filtre en temps réel sur les noms et identifiants des applications installées.
- **Bouton Top Bar** : Accès rapide depuis la barre supérieure (configurable via GSettings).
- **Raccourci touche Super** : Ouvre le menu d'applications directement en appuyant sur la touche Super / Windows.
- **Harmonie des couleurs d'accentuation** : S'adapte dynamiquement à la couleur d'accentuation définie dans les paramètres GNOME.
- **Gestion des favoris** : Clic droit sur n'importe quelle application pour l'épingler ou la détacher du dock / des favoris.
